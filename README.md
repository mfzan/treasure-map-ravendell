A hand-drawn treasure map of Widdershins Isle, drawn in pure Python with no dependencies. It is the chart Captain Barnaby Widdershins drew to remind himself where he buried the Widow's Dowry (300 doubloons, Mabel's, to be returned) — because he knew he would forget. Nine labeled places a sailor could actually find: Barnaby's Landing, Doubloon Beach, the Already-Dug Holes ("nothing (twice)"), Mt. Snore (the volcano that sleeps through everything), Gull Bluff, Rum Barrel Bay, the Widow's Dowry itself (the X, his last and shakiest guess), Mermaid's Rock, and the Kraken ("friendly, mostly"). A dotted route, a river, a compass rose that points north (probably), a ship, a sea serpent on holiday, and a note to whoever finds the map. Deterministic: two runs write byte-identical PNGs.

## Run it

```sh
python3 main.py
```
